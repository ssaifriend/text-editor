# M5 Markdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `.md` a first-class citizen: Sublime-style editing commands (bold/italic/code toggles, checkbox toggle, heading ±1, table align with Korean width, ordered-list renumber, URL-paste link wrap), heading folding, and a sanitized live preview tab (`markdown-it` → `DOMPurify` → `morphdom`) with `app-file://` local images, two-way scroll sync, and HTML/PDF export.

**Architecture:** Editing lives in `src/renderer/src/markdown/commands.ts` as pure `EditorState → TransactionSpec` functions wrapped as CM6 `Command`s and registered like the existing editor commands; markdown-only extensions (keymap, fold service, paste handler) are appended in `extensionsFor('markdown')`. The preview is a `preview` tab kind bound to a `bufferId`; `PreviewHost` renders the buffer's doc through `src/renderer/src/markdown/render.ts` (markdown-it with `data-line` injection + DOMPurify whitelist) and patches the DOM with `morphdom` on a 150 ms debounce. Main registers the `app-file` protocol (project-root-confined) and `export.pdf` / `export.html` handlers.

**Tech Stack:** `@codemirror/lang-markdown` (installed), `markdown-it@15.0.1`, `markdown-it-footnote@4.0.0`, `markdown-it-anchor@10.0.0`, `dompurify@3.4.15`, `morphdom@2.7.8`, `string-width@8.2.2`, `katex@0.18.7` (lazy, flag-gated), `@types/markdown-it@14.2.0`.

**Spec:** `docs/superpowers/specs/2026-09-08-text-editor-design.md` §3.3 (security: DOMPurify, `app-file://`), §3.5 (preview tab bound to buffer), §5.4 (마크다운), §6.2 (`app-file://` 경로 탈출 → 403), §8 M5 row.

## Global Constraints

- IPC via zod contracts (`src/shared/ipc.ts`), channel allowlists (`src/shared/channels.ts`), `IpcResult` responses.
- Renderer never touches disk; images come through `app-file://` served by main **only under the current projectRoot** (realpath-checked; `..` and symlink escapes → 403 + log).
- Preview HTML always passes DOMPurify (no `script`, no event handlers, `data-line` allowed, `img src` only `app-file:` or `https:` when `preview.allowRemoteImages`). CSP `img-src` gains `app-file:` and `https:` (the setting decides at render time; CSP is the outer fence).
- Preview render budget: 10k-line markdown < 50 ms for the markdown-it + sanitize step (unit test); DOM patch debounced 150 ms.
- Korean: table alignment uses `string-width` (Hangul = 2 columns); preview `lang="ko"`, `word-break: keep-all`.
- Commit directly to `main`, unsigned (`git -c commit.gpgsign=false commit`); E2E hidden.

```ts
import stringWidth from 'string-width'

export const isTableLine = (line: string): boolean => /^\s*\|.*\|\s*$/.test(line)

type Align = 'left' | 'center' | 'right' | null
const cells = (line: string): string[] => line.trim().replace(/^\|/, '').replace(/\|$/, '').split('|').map((c) => c.trim())
const isAlignRow = (cs: readonly string[]): boolean => cs.every((c) => /^:?-{1,}:?$/.test(c))
const alignOf = (c: string): Align => (c.startsWith(':') && c.endsWith(':') ? 'center' : c.endsWith(':') ? 'right' : c.startsWith(':') ? 'left' : null)

const pad = (text: string, width: number, align: Align): string => {
  const gap = Math.max(0, width - stringWidth(text))
  if (align === 'right') return ' '.repeat(gap) + text
  if (align === 'center') return ' '.repeat(Math.floor(gap / 2)) + text + ' '.repeat(gap - Math.floor(gap / 2))
  return text + ' '.repeat(gap)
}

export const formatTable = (lines: readonly string[]): string[] => {
  const rows = lines.map(cells)
  const cols = Math.max(...rows.map((r) => r.length))
  const alignRowIndex = rows.findIndex((r, i) => i > 0 && isAlignRow(r))
  const aligns: Align[] = Array.from({ length: cols }, (_, c) => (alignRowIndex >= 0 ? alignOf(rows[alignRowIndex]![c] ?? '---') : null))
  const widths = Array.from({ length: cols }, (_, c) =>
    Math.max(3, ...rows.filter((_, i) => i !== alignRowIndex).map((r) => stringWidth(r[c] ?? ''))),
  )
  return rows.map((r, i) => {
    if (i === alignRowIndex) {
      return `|${widths.map((w, c) => {
        const a = aligns[c]
        const dashes = '-'.repeat(w + 2 - (a === 'center' ? 2 : a ? 1 : 0))
        return a === 'center' ? `:${dashes}:` : a === 'right' ? `${dashes}:` : a === 'left' ? `:${dashes}` : dashes
      }).join('|')}|`
    }
    return `| ${widths.map((w, c) => pad(r[c] ?? '', w, aligns[c] ?? null)).join(' | ')} |`
  })
}
```

- [ ] **Step 4: Implement** `commands.ts` — each helper uses `state.changeByRange` (multi-cursor safe). Sketch:

```ts
import { EditorSelection, type EditorState, type TransactionSpec } from '@codemirror/state'
import type { Command } from '@codemirror/view'
import { formatTable, isTableLine } from './table'

const wordAt = (state: EditorState, pos: number) => state.wordAt(pos)

export const toggleWrap = (state: EditorState, marker: '**' | '*' | '`'): TransactionSpec | null =>
  state.changeByRange((range) => {
    const target = range.empty ? wordAt(state, range.head) : range
    if (!target) {
      const insert = marker + marker
      return { changes: { from: range.head, insert }, range: EditorSelection.cursor(range.head + marker.length) }
    }
    const text = state.sliceDoc(target.from, target.to)
    const before = state.sliceDoc(Math.max(0, target.from - marker.length), target.from)
    const after = state.sliceDoc(target.to, target.to + marker.length)
    if (before === marker && after === marker) {
      return {
        changes: [{ from: target.from - marker.length, to: target.from }, { from: target.to, to: target.to + marker.length }],
        range: EditorSelection.range(target.from - marker.length, target.to - marker.length),
      }
    }
    if (text.startsWith(marker) && text.endsWith(marker) && text.length >= marker.length * 2) {
      return { changes: { from: target.from, to: target.to, insert: text.slice(marker.length, -marker.length) }, range: EditorSelection.range(target.from, target.to - marker.length * 2) }
    }
    return {
      changes: [{ from: target.from, insert: marker }, { from: target.to, insert: marker }],
      range: EditorSelection.range(target.from + marker.length, target.to + marker.length),
    }
  })
```
`toggleCheckbox`: for each line in each range: `/^(\s*[-*+]\s+)\[( |x|X)\]\s/` → flip; `/^(\s*[-*+]\s+)(?!\[)/` → insert `[ ] `; if no line changed return null. `shiftHeading`: `/^(#{0,6})\s?/` on each line; new level = clamp(level + delta, 0, 6); return null if every line unchanged (e.g. 6 + 1). `renumberList`: from each range's first line walk up/down while lines match `/^(\s*)(\d+)\.\s/`; renumber per indentation level (counter map keyed by indent width, reset when a shallower indent appears). `alignTable`: expand cursor line to the contiguous `isTableLine` block; null if the cursor line is not a table line; replace block with `formatTable(lines).join('\n')`. `wrapSelectionAsLink`: single range, non-empty, no `\n` → `[text](url)`.

# M0 수동 IME 체크리스트

자동화(CDP) 테스트는 회귀 가드다. 실제 IME는 후보창·타이밍이 다르므로 아래를 사람이 직접 확인한다. 각 항목은 `pnpm dev`로 앱을 띄우고 `tests/e2e/fixtures/ime.ts`를 Open 버튼으로 열어 수행한다.

## 환경

| OS | 입력기 | 결과 | 확인자 | 날짜 |
|---|---|---|---|---|
| macOS | 시스템 2벌식 | | | |
| macOS | 구름 입력기 | | | |
| Windows | Microsoft 한국어 IME | | | |
| Windows | 날개셋 또는 구름 | | | |

## 항목 (각 OS·입력기 조합마다)

1. `const greeting = "";` 따옴표 사이에 커서를 두고 `한글`을 입력한다. 조합 중 글자가 한 번만 보이고, 완성 후 `"한글"`만 남는다. 자모가 분리되거나 글자가 두 번 들어가면 실패.
2. 조합 중(예: `하` 상태) `Esc`를 누른다. 조합이 취소되고 텍스트가 사라지거나, 입력기 규칙대로 `하`가 확정된다. 글자가 깨지면 실패.
3. 조합 중 오른쪽 화살표를 누른다. 조합이 확정되고 커서가 한 칸 이동한다.
4. `한글`을 입력한 뒤 `Cmd/Ctrl+Z` 두 번. 두 글자가 각각 또는 한 번에 사라진다. 자모 단위로 되돌아가지 않아야 한다.
5. `foo`에 커서를 두고 `Cmd/Ctrl+D` 두 번으로 커서 두 개를 만든 뒤 `한`을 입력한다. 두 위치 모두 `한`으로 바뀐다.
6. 상태바 `Col` 값이 `"한글"` 뒤에서 라틴 문자 기준이 아닌 글자 수 기준으로 증가한다(`한` 뒤 Col이 1만 증가).
7. 문장 끝에서 `Enter` 후 한글을 입력한다. 자동 인덴트가 조합을 깨지 않는다.
8. `.md` 파일을 열어 헤딩 안에서 한글을 입력한다. 마크다운 하이라이팅 데코레이션이 조합을 깨지 않는다.

## 판정

8개 항목이 모든 조합에서 통과하면 M0 수동 게이트 통과. 하나라도 실패하면 실패 조합·항목·현상을 `docs/superpowers/reports/m0-gate.md`에 기록한다.
